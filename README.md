# Portfolio Website

Personal portfolio website built to showcase my projects, skills, and experience as a **MERN Stack / Full-Stack Developer**.

## 📂 GitHub Repository
https://github.com/prashant1s/PortfolioPrashant

## 🚀 Tech Stack
- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- EmailJS
- HTML5 & CSS3

## ✨ Features
- Responsive and modern UI
- Animated hero section
- Projects showcase
- Contact form with EmailJS integration
- Optimized build using Vite
- Deployed on Render

## 🛠️ Installation & Setup

git clone: https://github.com/prashant1s/PortfolioPrashant.git
cd PortfolioPrashant
npm install
npm run dev
